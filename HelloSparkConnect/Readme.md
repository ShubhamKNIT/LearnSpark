# HelloSparkConnect

We are going to setup the Spark Remote connection using `DatabricksConnect` and create some sample result with stored table

## Requirements
0. Check the python and libraries mentioned below with databricks.
1. Install python in preferred env.
2. Python library requirements

    ```
    pyspark
    databricks-connect
    ```
3. Note: Version of libraries and python must match the remote connection you are making, to avoid any issues.
